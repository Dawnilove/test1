## 📌 [A-1] 천만까지 합 구하기

**1. 내용 정리** `for` 반복문을 사용하여 0부터 1,000,000까지의 숫자를 하나씩 더하며 합계를 구하는 방식입니다. `datetime` 모듈을 사용하여 연산에 소요된 시간을 측정하여 코드의 실행 속도를 확인합니다.

**2. 코드 (Code)**

Python

```
import datetime

tot = 0
start = datetime.datetime.now()

for i in range(10000001): tot += i

end = datetime.datetime.now()
print("time =", (end - start), tot)
```

**3. [실행결과]**

Plaintext

```
time = 0:00:00.415201 50000005000000
```

## 📌 [A-2] 천만까지 합 구하기 //빌트인 함수 사용

**1. 내용 정리** 파이썬 내장(Built-in) 함수인 `sum()`과 `range()`를 활용하여 천만까지의 합을 구합니다. 반복문을 직접 구현한 `[A-1]`에 비해 내부적으로 최적화된 빌트인 함수를 사용하는 것이 실행 속도가 훨씬 빠릅니다.

**2. 코드 (Code)**

Python

```
import datetime

start = datetime.datetime.now()

tot = sum(range(10000001))

end = datetime.datetime.now()
print("time =", (end - start), tot)
```

**3. [실행결과]**

Plaintext

```
time = 0:00:00.124503 50000005000000
```
