## 📌 [1-23] format 메서드 형식 지정

**1. 내용 정리** 포맷 문자열 내에서 콜론(`:`) 뒤에 형식을 지정하여 출력을 제어합니다.

- `d`, `x`, `f`: 10진수, 16진수, 실수 표현
    
- `<5`, `^5`, `>5`: 총 5자리를 기준으로 왼쪽, 가운데, 오른쪽 정렬
    
- `_`, `*`, `0`: 빈 공간을 채울 문자열 지정
    
- `,`, `%`: 천 단위 콤마 출력 및 백분율 표시
    

**2. 코드 (Code)**

Python

```

print('|{0:5s}|{0:5}|{1:2}|'.format('Hi','Good'))
print('|{0:5.1f}|{0:05.1f}|'.format(1.23))
print('|{0:<5}|{0:_^5}|{0:*>5}|'.format('Hi'))

print('{{{}}}'.format(123) )
```

## 📌 [1-24] f-prefix를 이용한 다양한 인쇄

**1. 내용 정리** 파이썬 3.6 이상부터 지원하는 `f-string` 기법입니다. 문자열 앞에 `f`를 붙이면 중괄호 `{}` 안에 외부 변수를 직접 작성할 수 있어 코드가 훨씬 간결하고 가독성이 뛰어납니다. 내부에서 연산이 가능하며 `.format()`과 동일한 형식 지정자를 사용할 수 있습니다.

**2. 코드 (Code)**

Python

```
name = 'mono'
age = 20
f1 = 11.3456

s = f'{name }, {age-10}'
print(s)

print(f'{f1:10.5f}')
print(f'name = {name}')
print(f'{age:>5}-{age:0>5}')
print(f'{age:<5}-{age:0^5}')
print(f'{123456789:,}')
print(f'{0.125:.2%}')
```

**3. [실행결과]**

Plaintext

```
mono, 10
  11.34560
name = mono
   20-00020
20   -02000
123,456,789
12.50%
```
